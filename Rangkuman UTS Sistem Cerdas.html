1Preprocessing pada Random Forest

Random Forest (RF) adalah ensemble dari banyak decision tree. Tiap pohon dilatih dengan sampel bootstrap (bagging) dan subset fitur acak. Hasil akhir: voting mayoritas (klasifikasi) atau rata-rata (regresi).

import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import classification_report

df = pd.read_csv("data.csv").drop_duplicates()
df = df.fillna(df.median(numeric_only=True))   # imputasi

# hapus outlier dengan IQR
Q1, Q3 = df["nilai"].quantile([0.25, 0.75])
IQR = Q3 - Q1
df = df[df["nilai"].between(Q1-1.5*IQR, Q3+1.5*IQR)]

X, y = df.drop("label", axis=1), df["label"]
X_tr, X_te, y_tr, y_te = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=42)

model = RandomForestClassifier(n_estimators=100, random_state=42)
model.fit(X_tr, y_tr)
print(classification_report(y_te, model.predict(X_te)))

6Tahapan Scaling

Menyamakan rentang nilai antar fitur. Penting untuk algoritma berbasis jarak/gradien (KNN, SVM, Neural Network, K-Means), tidak wajib untuk RF dan decision tree.

MetodeRumusHasilCocok untuk
Min-Max(x − min) / (max − min)0 – 1Data tanpa outlier ekstrem
Standardization (Z-score)(x − μ) / σMean 0, std 1Distribusi normal
Robust(x − median) / IQRTahan outlierData beroutlier
MaxAbsx / |max|−1 sampai 1Data sparse
Log Transformlog(x)Kurangi skewnessData miring
Aturan penting: fit scaler hanya pada data train, lalu transform pada train & test, agar tidak terjadi data leakage.

7Outlier

Nilai data yang menyimpang jauh dari pola data lainnya.

Penyebab: kesalahan input/pengukuran, noise, error sistem, atau kejadian ekstrem yang memang nyata.

Metode deteksi

Boxplot / IQRIQR = Q3 − Q1.
Outlier jika x < Q1 − 1,5·IQR atau x > Q3 + 1,5·IQR.
Z-scorez = (x − μ) / σ.
Outlier jika |z| > 3.
VisualisasiScatter plot dan histogram.
LanjutanIsolation Forest, DBSCAN, Local Outlier Factor.

Penanganan

  • Menghapus jika jelas error
  • Capping / Winsorizing: batasi ke batas atas/bawah
  • Imputasi dengan mean/median
  • Transformasi (misal log) untuk meredam pengaruh
  • Dibiarkan jika kejadian nyata yang penting (fraud/anomali)
